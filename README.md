# Lynq (Expo SDK 54)

React Native job discovery app.

## Stack
- Expo SDK 54
- React Native + TypeScript
- React Navigation (bottom tabs)
- AsyncStorage (saved jobs persistence)

## Run
1. `npm install`
2. `npm run start`
3. Open on iOS/Android simulator or Expo Go

## Notes
- The `figma/` folder is kept as the design/code reference source.
- Main app code is in `App.tsx` and `src/`.
